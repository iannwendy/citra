\section*{Appendix C. Verdict Taxonomy Specification}
\label{app:guideline}

CITRA assigns verification labels at the individual reference-entry level rather than labeling an entire student manuscript as AI-generated or human-written. The five mutually exclusive classes are defined as follows:

\begin{description}
    \item[\texttt{verified}] The cited publication exists in at least one authoritative scholarly database (Local FTS5 Corpus, Crossref, OpenAlex, DataCite, Global DOI RA, DOAJ, OpenAIRE/HAL, NCBI/bioRxiv, DBLP, arXiv, OpenLibrary, Europe PMC, or ACL Anthology); the normalized title matches closely; author surnames agree without fabricated co-authors; the publication year differs by at most one year (or matches a documented arXiv-to-proceedings transition); the work is not retracted; and any cited DOI resolves to the same work.
    \item[\texttt{metadata\_error}] The underlying scholarly work is genuine, but one or more bibliographic or contextual attributes are inaccurate: publication year off by two or more years, truncated or altered title, missing or grafted co-authors, mismatched venue, retracted status (\texttt{R-RETRACTED-PAPER}), contradicted body claim (\texttt{R-CONTENT-MISMATCH}), statutory issuing-authority mismatch (\texttt{R-VN-LEGAL-MISMATCH}), or broken URL on an otherwise verified record (\texttt{domain\_exception}).
    \item[\texttt{suspected\_hallucination}] No matching record is found across queried registries while live APIs returned clean HTTP 200 responses, or the citation contains an unregistered DOI prefix, a cross-work chimeric DOI splice (\texttt{R-CHIMERIC-DOI-MISMATCH}), a non-existent domain, or an impossible future publication year.
    \item[\texttt{unresolved}] Available evidence is insufficient to verify or refute the source, such as when external APIs experience HTTP 429 rate-limit exhaustion (\texttt{R-RATE-LIMITED-ABSTAIN} / \texttt{R-API\_EXHAUSTED}), a regional DOI agency registers the handle without public CSL metadata (\texttt{R-DOI-RA-NO-CSL}), or title similarity falls inside the $[0.40, 0.60)$ abstention zone (\texttt{R-ABSTENTION-BORDER}).
    \item[\texttt{resource}] The entry refers to a non-article web page, open-source repository, Hugging Face model or dataset card, IETF RFC or PyPI package specification, official technical manual, or Vietnamese statutory document (\begin{vietnamese}\texttt{Luật}, \texttt{Nghị định}, \texttt{Thông tư}, \texttt{Quyết định}\end{vietnamese}).
\end{description}

\section*{Appendix D. Codebase Package Map}
\label{app:modules}

The repository (\texttt{v3.90.1}) separates backend domain packages (\texttt{src/\allowbreak integrity\_checker/}) from the single-page web client (\texttt{web/src/}) across the following core modules:

\begin{description}
    \item[\texttt{extraction/}] Multi-format parsers for PDF (GROBID \texttt{0.9.1-crf} TEI-XML, two-column PyMuPDF, \texttt{pdfplumber}, and selective Tesseract Vietnamese OCR), DOCX (\texttt{python-docx}), BibTeX, and RIS, alongside table-of-contents filtering and twelve citation-style extractors.
    \item[\texttt{linking/}] Bidirectional \texttt{CitationLinker} implementing seven ordered resolution methods, composite sub-reference splitting (\texttt{[14a, 14b]}), duplicate detection, and eight \texttt{MappingStatus} states.
    \item[\texttt{database/}] Offline SQLite FTS5 scholarly index (\texttt{local\_papers.db}, 129,125 records covering 128,105 unique papers and 82,877 full abstracts) using WAL mode and Okapi BM25 ranking.
    \item[\texttt{retrieval/}] Domain-aware \texttt{RetrievalOrchestrator}, 101-paper seminal whitelist, asynchronous clients for 15+ registries, Retraction Watch screening, per-provider circuit breakers, singleflight request coalescing, persistent SQLite cache, and SSRF-hardened \texttt{LinkValidator} + \texttt{SafeHtmlMetaVerifier}.
    \item[\texttt{matching/}] RapidFuzz lexical matching, Vietnamese-aware \texttt{author\_matcher}, \texttt{VenueNormalizer}, Sentence-BERT (\texttt{all-MiniLM-L6-v2}) title and abstract evidence alignment, citation intent/stance classification, and ONNX INT8 multilingual (\texttt{VI} $\leftrightarrow$ \texttt{EN}) bridging.
    \item[\texttt{logic/}] \texttt{NeuroSymbolicChecker}, Order 0 pre-screening plus 16 priority-ordered rule groups (68 distinct \texttt{R-*} identifiers), \texttt{VNLegalVerifier}, 16-feature \texttt{HybridMLScorer} ($C = 2.0$), logit-space \texttt{PlattCalibrator} ($a = 1.807661, b = 1.115955$), \texttt{CISCalculator}, and bilingual explanation templates.
    \item[\texttt{pipeline/} \& \texttt{models/}] Singleton \texttt{IntegrityPipeline} coordinating all eight stages and Pydantic domain schemas shared across extraction, retrieval, verification, and API serialization.
    \item[\texttt{evaluation/}] Paper-disjoint 120,000-sample benchmark generator and runner, baseline ladder (\texttt{B0}--\texttt{B5}), 2,400-sample OOD guardrail suite, 120-reference E2E gold evaluator, and paired McNemar, Holm--Bonferroni, Clopper--Pearson, and bootstrap tests.
    \item[\texttt{export/}] Sanitized report exporters (PDF, DOCX, CSV, JSON, BibTeX, RIS), \texttt{bibliography\_formatter.py}, and automated bibliography repair for \texttt{.docx} manuscripts (\texttt{docx\_exporter.py}).
    \item[\texttt{db/}, \texttt{billing/} \& \texttt{api/}] Fifteen SQLAlchemy ORM models, thirteen SHA-256 checksummed schema migrations (\texttt{0001}--\texttt{0013}), adaptive SQLite WAL tuning, \texttt{PipelineAdmissionController}, stale-job recovery, Stripe/VNPay billing handlers, and FastAPI routes under \texttt{/api/*}.
    \item[\texttt{web/}] React 18.3 and TypeScript 5.8 single-page application (\textbf{CITRA}) tested by 487+ Vitest unit/component tests (63 suites) and 20 Playwright E2E specification suites.
\end{description}
